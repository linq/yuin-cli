## 核心实现

- `domain` 保存稳定的平台歌曲 ID、专辑／时长／封面及 LX hash、albumId、音质映射。重复入队使用独立 UUID；持久身份不保存临时音频 URL。
- `catalog` 移植参考桌面版五平台公开目录请求／解析，保留来源与许可说明。网易云按完整有序 trackIds 分页补详情，完整保存会核对数量、重复和拉取进度；不把预览当整单。
- 推荐接口没有可信总数时返回 `total: null`。酷狗推荐页容量为实际 20 条；酷我提供 6 个预置常用榜单，榜单歌曲仍完整分页。各平台失败独立报错，不自动换成别的平台同名歌曲。
- `source` 使用独立 rquickjs/QuickJS worker，限制 VM 128 MiB、栈 1 MiB、脚本 9 MB、协议帧 1 MiB；初始化 15 秒、解析 65 秒。超时先关闭输入协作取消，500 ms 后终止。脚本不拥有文件、Shell、Node 模块能力；仍可访问网络，不宣称完整 OS 沙箱。
- LX bridge 支持 API 2.0、request/inited 生命周期、能力和音质检查、Promise、定时器、HTTP／取消、字节编码、MD5、随机字节、AES CBC/ECB、LX 1024-bit 零填充 RSA 与 zlib。HTTP 单响应 8 MB，最多 8 个源 HTTP 请求。stdout 只承载协议，不记录解析 URL、请求头或完整脚本。
- 导入／更新先对候选快照初始化；失败保留原记录／worker。激活与更新不会自动切换到其他源，脚本快照启动前重新校验 SHA-256。
- `app` 串行拥有播放状态与队列；目录详情在客户端请求任务获取，源解析和 mpv 加载在可取消的 generation 任务执行。解析／缓冲期间暂停、切歌、音量和关闭命令仍能响应。
- CLI 播放请求等待加载结果，能返回明确错误；TUI 使用已接受后独立继续的加载请求，q 退出界面不取消已接受的播放。断开未完成的普通请求会取消加载并回滚该请求的新增项，不丢弃其他客户端入队的歌曲。
- mpv 使用私有继承 socketpair，不创建公开播放器控制端点；禁用配置、自动脚本、默认按键、独立媒体键处理、终端输入、视频和外部文件自动加载。流媒体请求头仅通过私有 IPC 设置。daemon 强制退出后播放器随连接关闭退出。
- `storage` 专用线程持有 SQLite 写入端；schema v1–v3 迁移、外键、busy timeout、迁移前备份。队列事务保存；位置每五秒单独 checkpoint，正常控制和退出也保存。重启恢复暂停状态。
- `download` 最多两首并发，可配置为一首，最多 100 个待处理任务；可取消／重试。流式 `.part`、512 MiB 限制、HTTP／签名／完整解码／音质检查，完整文件通过同文件系统 hard-link 原子发布且不覆盖目标。退出／取消清理临时文件；异常中断任务恢复为可解释的取消状态。每个任务保存目标目录和自己的临时路径，恢复不扫描删除共用目录中其他任务的文件。
- 音质检查读取编码信息；FLAC 24-bit 从 STREAMINFO 读取，普通档核对平均码率。离线文件加载前重新解码并校验 SHA-256。该检查不认证原始录音或排除有损转码。
- TUI 默认歌单页，有真实搜索、目录、个人列表、下载、队列、播放状态、歌词和输入焦点。旧查询不覆盖新查询；按稳定 ID 保留选中项，追加页与返回保留滚动。小窗口可切焦点查看折叠队列；输入时 Space/j/k/q 为文本。
- 配置私有文件原子保存，支持默认平台／音质／目录／并发、中英文、终端／深／浅主题、0–10 秒旧曲淡出和可选媒体控制。请求 `--platform` 不改变默认偏好。
- 歌词提供五平台请求／解码、LRC/KRC 时间与逐字标签、偏移、翻译合并、二分当前行、离线缓存；本地音频可读同名 `.lrc`。
- 系统媒体控制通过 souvlaki：macOS 启用时运行 AppKit 主线程事件循环，Linux 使用用户 D-Bus 会话；不安装辅助功能钩子。设置 media_keys 后需要重启 daemon。
- JSON 导入默认只预览；显式 commit 后先生成 SQLite 快照，再事务合并个人列表、未启用源、历史和验证通过的既有下载。旧队列明确计入“未导入”，保持现有播放／队列和偏好。导出不覆盖目标，仅显式 include-sources 时携带脚本。

- 常规测试：**27 项通过，0 失败，1 项真实 mpv 检查默认忽略**。包含 6 项单元测试、4 项原有 CLI 集成测试、14 项 daemon 检查、1 项完整服务 fixture 流程、2 项 worker 资源／断开检查。
