# Yuin 0.1.0

首个 Rust CLI/TUI 版本，采用 Apache-2.0 许可证。

- 共享后台播放、队列、播放模式、音量和断点恢复；退出 TUI 后继续播放。
- 网易云、酷我、QQ、酷狗、咪咕目录查询与分页；独立 QuickJS 音乐源进程。
- 下载校验、取消与重试、离线播放、个人歌单、收藏、历史和歌词。
- 中英文、主题、可选系统媒体控制、迁移预览、备份和导出。

## 安装

按系统与 CPU 选择 `.tar.gz`，校验相邻 `.sha256` 文件后解压，将 `bin/yuin` 放到 PATH。macOS 也可使用对应架构的 `.pkg`。

**mpv 需要单独安装**：macOS 可运行 `brew install mpv`；Linux 使用发行版软件包。在线播放还需显式导入并启用可信音乐源，发行包不包含第三方源或音乐。

Release 附件 `yuin.rb` 为使用这些归档校验值生成的 Homebrew 公式；发行包同时提供手册、补全和许可证说明。

## 已知限制与验收范围

- macOS 安装包未进行 Apple Developer 签名或公证。
- 三平台 CI 检查和原生构建不替代音频设备与物理按键验收。实际媒体键、耳机按键、音频设备切换和长期运行仍需真机验证。
- 本机已完成真实 mpv、TUI 交互、五平台样本播放与下载后离线播放验证；不保证所有第三方源、歌曲或音质持续可用。
- Windows 播放不在本次发行范围；mpv 与音乐源均为外部依赖。

完整使用方法见仓库双语 README，详细验证记录见 `docs/STATUS.md`。
