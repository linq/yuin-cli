# Yuin 0.1.1

- 内置 Symphonia 解码与 Rodio/CPAL 音频输出，支持本地和网络播放，不再需要单独安装 mpv。
- 保留暂停／继续、音量、定位、切歌、旧曲淡出和重启暂停恢复；网络缓存有大小与超时限制。
- 修复歌词视图中队列选中歌曲的封面不更新：队列焦点显示选中项，歌词焦点显示实际播放；底部小封面始终跟随播放。
- 包含歌单搜索、整个歌单收藏／播放、最多 10,000 首队列、Macchiato 配色和独立封面预览。
- 更新诊断、依赖说明和自动验证，默认测试使用真实解码与无声输出，不访问音频设备。

## 安装

按系统与 CPU 选择 `.tar.gz`，校验相邻 `.sha256` 文件后解压，将 `bin/yuin` 放到 PATH。macOS 也可使用对应架构的 `.pkg`。

macOS 使用系统 CoreAudio，无需安装 mpv 或 Homebrew 音频库。Linux 使用系统 ALSA。在线播放仍需显式导入并启用可信音乐源，发行包不包含第三方源或音乐。

升级后先运行 `yuin daemon stop`，再打开新版本 TUI，后台服务才会使用新后端。队列和进度保留，重新启动默认暂停。

Release 附件包含压缩包、macOS 安装包、SHA-256、manifest 和 Homebrew 公式；压缩包内提供手册、补全及依赖许可证。

## 后台播放

- `yuin pause`：暂停，保留当前歌曲和进度。
- `yuin stop`：停止，保留队列，重置当前歌曲和进度。
- `yuin daemon stop`：停止音频并关闭后台服务。
- TUI 空格暂停／继续，`s` 停止，`q` 只退出界面并保留后台播放。

## 验证范围

本机已通过格式、clippy、自动测试、CoreAudio 输出和终端交互检查。macOS 安装包未签名／公证；物理媒体键、音频设备热切换、Intel/Linux 真机播放仍需对应环境验收。Windows 播放不在本次发行范围。
